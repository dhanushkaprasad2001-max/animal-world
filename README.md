# Animal World

A responsive educational animal guide website built with HTML, CSS and JavaScript.

## Publish with GitHub Pages
1. Open the repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. After GitHub finishes publishing, visit `https://dhanushkaprasad2001-max.github.io/animal-world/`.

The home page includes searchable animal profiles and category filters. Images are loaded from Unsplash; an internet connection is required for remote images and Google Fonts.
